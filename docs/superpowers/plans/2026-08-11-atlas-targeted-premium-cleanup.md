**Goal:** Clean up the Atlas Barbell Club front page so each anchor section renders reliably, feels premium, and avoids repeated card and label patterns while preserving the current brand identity.

- [ ] **Step 5: Add hash reveal behavior**

In `src/main.js`, after `revealNow`, add:

```js
const revealWithin = (root) => {
  if (!root) {
    return;
  }

  if (root.matches("[data-reveal]")) {
    revealNow(root);
  }

  root.querySelectorAll("[data-reveal]").forEach(revealNow);
};

const revealHashTarget = () => {
  const hash = window.location.hash;

  if (!hash || hash.length < 2) {
    return;
  }

  const target = document.getElementById(decodeURIComponent(hash.slice(1)));
  revealWithin(target);
};
```

After the IntersectionObserver setup block, add:

```js
revealHashTarget();
window.addEventListener("hashchange", revealHashTarget);
```

Do not add a scroll listener. Hashchange is event-based and safe.
